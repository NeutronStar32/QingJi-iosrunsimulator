把手机当前位置标在电脑地图上

首次在「快捷指令」创建一次，以后每次点击运行即可回传。扫码打开的是设置说明，不会直接获取定位，也不是可安装的快捷指令。

推荐扫码版：只需修改一次快捷指令。以后先运行快捷指令，再扫电脑上的“② 回传地址”二维码；不用手动复制 URL。请勿扫“① 设置说明”码。

  1. 打开 iPhone「快捷指令」，新建或编辑 轻迹当前位置。
  2. 在最上方添加 扫描二维码或条码（搜索“扫描”或“条码”）。
  3. 添加 获取当前位置。首次运行时允许定位，开启精确位置。
  4. 添加 获取位置的详细信息，属性选择 纬度，输入选择「获取当前位置」输出的「当前位置」。
  5. 再添加 获取位置的详细信息，属性选择 经度。输入也选「当前位置」，不要使用上一步的纬度。
  6. 在 获取 URL 内容 中，删除原来写死的地址，轻点 URL 输入框，选择 选择变量，再点最上方 扫描二维码或条码 的输出作为地址。不同系统版本可能显示为“二维码／条码”或“扫描结果”；关键是选扫描动作的输出，不要选经度。
  7. 展开“获取 URL 内容”：方法选 POST，请求体选 JSON。添加两个字段：
    latitude → 插入「纬度」动作的输出变量
    longitude → 插入「经度」动作的输出变量
    字段可以选数字；若使用文本字段，也要插入变量。

使用时：电脑开启接收 → 手机运行“轻迹当前位置” → 在弹出的扫描画面对准电脑“② 回传地址”码 → 等待回传完成。用普通相机扫描回传地址不会自动发送位置。

回到电脑开启接收窗口，然后运行快捷指令。允许快捷指令访问位置、本地网络和上述地址。看到“电脑已收到”即回传成功；电脑地图会自动居中。

手机与电脑应在同一 Wi-Fi／局域网。每次接收窗口为 10 分钟；点击电脑“开启／延长接收”可延长。重启电脑程序或关闭接收后地址会改变；扫码版只需重新开启接收并扫描新码。原来的手填地址版仍需更新 URL。HTTP 回传仅适合可信的局域网；不经过外部服务器。若手机正在使用模拟定位，快捷指令可能返回模拟位置，因此地图标记为“手机上报位置”。

若无法访问此页面：检查 Wi-Fi、电脑所选 IP、路由器设备隔离，以及 Windows 是否允许 Python 在专用网络接收连接。
