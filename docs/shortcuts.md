# 手机位置回传

电脑不通过 USB 读取实时 GPS，也不使用电脑的位置代替手机位置。需要时在 iPhone 运行快捷指令上报；它不是后台实时追踪。

1. 手机与电脑连接同一局域网或热点。展开“设置手机位置回传”，选择对应的电脑 WLAN 地址，开启接收。
2. 用普通相机扫“① 设置说明”二维码，查看完整设置步骤。
3. 快捷指令开头加入“扫描二维码或条码”。随后获取当前位置，再分别提取同一个位置的纬度与经度。
4. 在“获取 URL 内容”的 URL 位置选择扫描动作的输出变量，方法选 POST，请求体选 JSON。
5. JSON 字段 `latitude`、`longitude` 分别插入纬度、经度变量，允许定位、精确位置及本地网络访问。
6. 每次使用先运行快捷指令，再在它的扫描界面扫描电脑上的“② 回传地址”码。

接收窗口为 10 分钟，可延长。重启程序、关闭接收或更换网络后重新开启并扫描新码即可；手填固定地址的旧快捷指令仍需更新地址。

校园网可能隔离设备。使用热点时，确保手机和电脑处于同一热点并选对 WLAN 地址。可先在手机访问 `http://电脑IP:8766/` 测试连通性。

回传使用可信局域网内的 HTTP，配对地址不要分享。位置只保存在程序内存中。手机处于模拟定位时，上报也可能是模拟值；恢复后需确认手机位置并重新上报，网页才显示新标记。
