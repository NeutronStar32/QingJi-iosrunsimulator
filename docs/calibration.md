# 多组本地校准

配置文件为 `data/calibration.json`，已被 Git 忽略。源码只包含不含个人位置的 `config/calibration.example.json`；不要用示例覆盖已有有效配置。完整复制示例与首次创建命令见 [README](../README.md#新建偏移校准配置)。

## 一组对应一个区域

文件最外层为对象，`profiles` 数组中每个对象是一组修正参数：

| 字段 | 含义 |
| --- | --- |
| `name` | 唯一、非空的组名，网页显示实际采用的名称 |
| `enabled` | 小写布尔值 `true` 开启、`false` 关闭，不加引号 |
| `origin_lat_lng` | 中心纬度、经度，使用 WGS84 |
| `axis_scales` | 东西、南北缩放比例，均大于零 |
| `shift_east_north_m` | 向东、向北的平移米数，负数表示反方向，缩放后平移 |
| `radius_m` | 适用半径，单位米，大于零 |

新增地点时复制完整的一组，修改名称、开关和参数，组间用逗号分隔。各组名称不得重复，JSON 中不能写注释或末尾多余的逗号。即使关闭的组也应保留合法的字段与数值。

## 启动读取与选择

修改文件后，退出并重新启动程序。程序启动时读取一次，当前进程运行期间不重新读盘。网页会显示配置文件、读取与启用的组数和组名；没有文件或没有启用的组时使用原坐标。配置无效会显示错误，启用修正的定位操作会被拒绝，修复后重启。

网页总开关关闭时不使用任何校准。总开关开启时，只从 `enabled: true` 的组中选择能覆盖单点或整条路线的组。如果有多组符合，选择距单点／路线起点最近的一组，等距时按文件顺序。没有一组覆盖整条路线时，整条路线使用原坐标。

一次任务固定一组参数，不叠加、不在组之间切换，暂停和持续保持也沿用该组。地图目标、关键点和路线文件保留原坐标，只在发送手机时补偿一次；跑步距离与配速按补偿后的路线计算。轨迹偏移在补偿后的米制空间计算。

旧版单组 JSON 格式仍兼容，未写 `enabled` 时默认为 `true`。现有本机配置已迁移为“原操场校准”，数值不变，并在同目录保留旧配置备份 `calibration.legacy.json`；程序只读 `calibration.json`，不会自动扫描备份文件。

校准是对应地点的局部视觉对齐，不是通用地图坐标转换。
